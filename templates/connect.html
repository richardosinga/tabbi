Connect Tabbi to your AI

Tabbi works as an MCP integration with Claude, ChatGPT, Gemini, Cursor, Windsurf, and other AI assistants. Takes about 30 seconds to set up.

AI assistants via MCP

Claude (Web) Recommended
  1. Go to claude.ai → Settings → Integrations
  2. Click Add integration and paste the URL below
  3. Start a new conversation and describe your trip
https://tab.bi/mcp
Claude Code (CLI)
  1. Run the command below in your terminal
  2. Start Claude Code and describe your trip
claude mcp add tabbi https://tab.bi/mcp
Cursor
  1. Open Cursor Settings → MCP
  2. Add a new server with the URL below
  3. Restart Cursor and start chatting
https://tab.bi/mcp
Windsurf
  1. Open Windsurf Settings → MCP Servers
  2. Add a new server with the URL below
  3. Restart and start chatting
https://tab.bi/mcp
ChatGPT
  1. Go to chatgpt.com → Settings → Connected apps
  2. Click Add MCP server and paste the URL below
  3. Start a new chat and describe your trip
https://tab.bi/mcp
Gemini
  1. Open gemini.google.com → Extensions → MCP servers
  2. Add a new server with the URL below
  3. Start a conversation and describe your trip
https://tab.bi/mcp

What your AI can do with Tabbi

plan_trip Create a new multi-city trip plan
open_plan Open an existing trip using your passphrase
research_city Find the best places to visit, eat, and drink in a city
add_pois_to_plan Add world66 places directly to a stop
submit_pois Submit newly researched places to your plan
remove_poi_from_plan Remove a place from a stop
search_world66 Search the world66 travel guide
geocode Look up coordinates for a place (used for map pins)
No account needed. Your trips are protected by a passphrase. Your AI will ask for it the first time you open a plan, and remembers it for the rest of the conversation.
